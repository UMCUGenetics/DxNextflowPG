# Custom Modules 
Custom (Nextflow) modules is similar to NextflowModules in terms of structure, using `tool/version/process.nf`

Any custom module or nextflow process that is specific for this workflow, should be added to CustomModules instead of NextflowModules.
When a tools license restricts us in using it publicly, the process is added to CustomModules instead of NextflowModules as well.
